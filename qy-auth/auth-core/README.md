# 说明

权限体`IAuthObject`分为两部分:
- 一部分是配置权限使用的，如`SimpleAuthObject`，
- 另一部分是用户拥有的权限，如`UserAuthInfo`

区别在于`SimpleAuthObject`是单纯的权限配置，会涉及到权限字符串的反解析，解析成权限对象，
而`UserAuthInfo`是用户自己的权限对象，其包含了自己的父级机构等，不会设计到反解析（目前的设计也反解不出来，如RELATIONDEPT__1，无法反解析获取到其是哪个部门的父部门）;

## 权限体缺失时的对外结果

- `UserAuthInfo` 的用户部分缺失时，`listBaseAuth()` 返回空权限集合而不抛异常。连用户都装载不出来的权限体，
  它产出的任何权限都不可信，让它参与判定等于把装载层的缺陷伪装成数据问题
- 权限体本身为 null（例如用户没有凭证记录时装载不出权限体）时，认证装载仍正常返回该用户的认证主体，权限集合为空
- `RELATIONDEPT__<部门ID>` 只覆盖该部门的严格子孙部门成员，本部门自己的成员由 `DEPT__<部门ID>` 覆盖，两个标记正交
