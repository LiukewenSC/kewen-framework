# Spec Delta

## ADDED Requirements

### Requirement: 权限体能否反解的差异由示例承载

该示例 MUST 用示例自有的权限实体，把"配置侧权限体可反解往返、用户侧权限体不可反解"这一核心层能力差异做成可指认的用例。不可反解 MUST 表现为明确失败并被用例断言，MUST NOT 退化成静默返回空集合。用例所需的部门层级数据由示例自己的表提供，MUST NOT 借用权限模型层的代码或表。

#### Scenario: 继承型标记在示例内可声明并参与判定

- **WHEN** 用示例自有的继承型权限实体声明一条权限并授予某个演示端点
- **THEN** 拥有该串的用户获得放行、没有的用户得到拒绝
- **AND** 判定结果只取决于权限串是否一致，与示例自定义实体的其他字段无关

#### Scenario: 反解用户权限体得到明确失败

- **WHEN** 对示例中充当用户权限体的对象执行"权限串反解为对象"
- **THEN** 得到可识别的失败结果
- **AND** 用例断言的是这个失败，而不是一个空集合

#### Scenario: 层级数据不出示例自己的表

- **WHEN** 检查该示例为演示层级关系所需的建表与种子内容
- **THEN** 其中不出现权限模型层定义的任何表名
- **AND** 示例使用的业务主键仍全部为整型
