# Spec Delta

## ADDED Requirements

### Requirement: 以文件库承载数据的示例在重启后保留数据

选择了可持久化数据文件的示例工程，其建表和种子脚本 MUST 可以被重复执行而不改变已有表结构、不重复写入种子行、不清空使用者在使用中改过的数据；其数据文件 MUST 位于该示例工程自己的目录内，并 MUST NOT 进入版本库。

#### Scenario: 重复启动不破坏已有内容

- **WHEN** 使用者在同一个数据文件上多次启动并关闭该示例
- **THEN** 已建立的表结构保持不变
- **AND** 种子数据不产生重复行
- **AND** 使用者在使用中新增或修改的数据在重启后仍然存在

#### Scenario: 首次启动自动获得表结构

- **WHEN** 在一个还没有数据文件的位置首次启动该示例
- **THEN** 启动完成后所需的表已存在且种子数据已写入
- **AND** 不需要使用者手工执行任何脚本

#### Scenario: 重置有确定路径

- **WHEN** 使用者想把示例恢复到初始状态
- **THEN** 通过文档中指明的一条操作即可回到首次启动的结果，且该操作只影响该示例自己的数据文件

#### Scenario: 数据文件不进入版本库

- **WHEN** 检查仓库的版本库忽略配置
- **THEN** 该示例的数据文件所在路径被忽略
