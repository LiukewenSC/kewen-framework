# identity/authentication-principal Specification

## Purpose

约束各认证协议在认证成功后交给调用方的认证主体：主体类型必须与协议无关、账号信息与权限一律来自本系统、协议自身所需的原生数据仍要留在主体上，使依赖认证主体的协议级功能不因主体统一而退化。

## Requirements

### Requirement: 各认证协议产出同一种认证主体

系统 SHALL 在账号密码、OAuth2、OIDC 与 SAML2 认证成功后，把同一个框架用户类型作为认证主体写入安全上下文。消费方读取当前登录用户 MUST NOT 依赖本次登录走了哪种协议。

#### Scenario: 任一协议登录后读取当前用户

- **WHEN** 用户通过账号密码、OAuth2、OIDC 或 SAML2 中任一种方式完成登录，随后在该会话内读取当前登录用户
- **THEN** 得到的都是同一个框架用户类型，携带本系统的主键、用户名与权限集合
- **AND** 读取过程不需要调用方判断本次登录属于哪种协议

#### Scenario: 认证对象的权限集合与当前用户一致

- **WHEN** 消费方读取认证对象上的权限集合
- **THEN** 其内容与当前登录用户的权限集合一致
- **AND** 不包含身份源的作用域声明或协议自带的权限对象

### Requirement: 单点登录身份在协议校验阶段映射到本地账号

系统 SHALL 在完成身份断言校验、取得身份源主体之后，以该主体所标识的用户名向本系统的用户详情服务取得账号信息，再据此建立认证主体。当前登录用户的权限 MUST 来自本系统，MUST NOT 取自身份源返回的权限或角色声明。

#### Scenario: 身份源只证明身份不授权

- **WHEN** 身份源返回的声明中包含权限、角色或展示信息之类的字段
- **THEN** 当前登录用户的权限集合与展示信息仍全部来自本系统账号数据

#### Scenario: 映射字段按客户端独立配置

- **WHEN** 同一应用内两个客户端各自配置了不同的映射字段，且两个字段在身份源返回中指向不同的值
- **THEN** 系统分别以各自配置字段的值作为本地用户名查找
- **AND** 一个客户端的映射字段配置不影响另一个客户端

### Requirement: 本地无对应账号时拒绝登录

当身份源认证通过但本系统不存在对应账号时，系统 SHALL 使该次认证失败并给出可与其他认证失败区分的原因，MUST NOT 建立权限集合为空或仅由身份源声明构成的已登录会话。

#### Scenario: 身份源有此人而本系统无账号

- **WHEN** 单点登录取得的身份源主体在本系统查不到对应账号
- **THEN** 本次认证以失败结束，失败原因可与其他认证失败区分
- **AND** 该会话不被标记为已登录
- **AND** 单点登录的重定向交付姿态与既有认证失败保持一致

### Requirement: 登录后的账号数据为会话期快照

系统 SHALL 在建立认证主体时一次性取定账号信息与权限。本系统账号数据在此之后发生变化 MUST NOT 影响已建立会话的当前登录用户，变更需重新登录后生效。

#### Scenario: 登录之后权限被修改

- **WHEN** 用户已完成单点登录，随后本系统修改了该用户的权限，该用户再次读取当前登录用户
- **THEN** 返回的权限集合仍是登录时刻的内容
- **AND** 本次读取不再访问本系统的账号存储

### Requirement: 协议原生数据保留在认证主体上

系统 SHALL 使单点登录的认证主体保留该协议后续流程所需的原生数据。依赖认证主体的协议级功能 MUST 在主体统一后仍然可用：OIDC 的会话终止请求可取得 ID Token；SAML2 的服务发起单点登出可取得所属注册标识与断言会话索引。

#### Scenario: OIDC 登录后主体仍满足会话终止的判定条件

- **WHEN** 已通过 OIDC 登录的会话被取出认证对象
- **THEN** 其主体仍是 `OidcUser` 的实现且能取到本次的 ID Token
- **AND** 因此依赖该判定的 relying party 会话终止（`id_token_hint`）不因主体统一而失效
- **AND** 该功能本身在本框架尚未接入过滤器链，接入与否不受本变更影响

#### Scenario: SAML2 登录后发起服务侧单点登出

- **WHEN** 已通过 SAML2 登录的会话发起服务发起的单点登出
- **THEN** 系统能定位该会话所属的服务注册项并向身份源发出登出请求
- **AND** 登出请求包含该断言的会话索引

### Requirement: 登录成功响应体的字段来源随主体统一

系统 SHALL 保持登录成功响应体的字段集合与结构不变。单点登录下的字段值 MUST 改为来自映射后的本地账号，而不是身份源返回的声明。

#### Scenario: 单点登录以 JSON 结束时字段来自本地账号

- **WHEN** 单点登录成功且应用未配置回跳目标，流程以与账号密码相同的 JSON 响应体结束
- **THEN** 响应体的字段集合与账号密码登录一致，各字段值来自本地账号数据
- **AND** 会话标识与登录时间仍按既有规则写入
