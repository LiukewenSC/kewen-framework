# storage/file-storage Specification

## Purpose
约束对象存储中对象键（key）的生成规则，以及存储区域、回调地址、传输协议等端点参数是否可由使用方配置，保证服务端直传与客户端直传两条路径对同一文件得到同一个键。

## Requirements

### Requirement: 单一键生成规则贯穿全部上传路径

系统 SHALL 用同一套规则为服务端直传与客户端直传生成对象键。对相同的根目录、相对目录与文件名输入，两条路径产出的键 MUST 完全一致。

#### Scenario: 两条路径生成同一文件的键

- **WHEN** 分别以服务端正直传和客户端直传上传相对目录与文件名均相同的文件
- **THEN** 两者得到相同的对象键
- **AND** 服务端直传所签发上传凭证中绑定的键，与实际提交给存储服务的键是同一个值

#### Scenario: 凭证绑定键与实际提交键不一致

- **WHEN** 上传凭证按某个键签发，而提交时使用另一个键
- **THEN** 该组合不被允许存在于实现中，因为它会导致上传被存储服务拒绝

### Requirement: 空路径段不产生多余分隔符

拼接对象键时，系统 SHALL 跳过为空或仅含空白的路径段，MUST NOT 产出前导分隔符、尾随分隔符或连续分隔符。

#### Scenario: 根目录未配置

- **WHEN** 存储根目录为空字符串或未配置，相对目录为 `avatar`，文件名为 `a.png`
- **THEN** 生成的键为 `avatar/a.png`
- **AND** 不出现 `/avatar/a.png` 这样的前导分隔符

#### Scenario: 相对目录为空

- **WHEN** 根目录为 `app`，相对目录为空，文件名为 `a.png`
- **THEN** 生成的键为 `app/a.png`

### Requirement: 端点参数由配置提供

存储区域、异步处理通知地址 SHALL 可经配置设定。异步处理通知地址 MUST NOT 指向任何特定部署环境的内置默认值。

#### Scenario: 未配置异步处理通知地址

- **WHEN** 使用方未在配置中提供异步处理通知地址
- **THEN** 上传凭证中不包含该策略项
- **AND** 系统不使用任何硬编码的第三方域名作为默认值

#### Scenario: 变更存储区域

- **WHEN** 使用方将存储区域由华南改为其他区域
- **THEN** 仅通过配置即可完成变更，无需修改框架源码

### Requirement: 与存储服务 API 的通信使用加密传输

系统与存储服务 API 之间的上传通信 SHALL 使用 HTTPS。下载链接是否使用 HTTPS SHALL 可配置，且其默认值 MUST NOT 使尚未配置证书的自定义域名失效。

#### Scenario: 服务端直传

- **WHEN** 框架向存储服务 API 发起上传
- **THEN** 使用加密的 API 域名

#### Scenario: 下载域名尚未配置证书

- **WHEN** 使用方未显式开启下载链接加密
- **THEN** 生成的下载链接保持非加密协议，行为与本变更之前一致
