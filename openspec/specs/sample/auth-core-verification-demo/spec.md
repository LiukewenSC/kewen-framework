# sample/auth-core-verification-demo Specification

## Purpose

提供一个只依赖权限核心层的示例，使其每一项规格场景都有可指认的端到端验证载体，并证明核心层不依赖任何具体权限模型的实现。

## Requirements

### Requirement: 示例只通过核心层的扩展点交付能力

该示例 MUST 只依赖权限核心层，并由示例自己提供核心层要求的全部扩展点实现。示例 MUST NOT 依赖任何具体权限模型层的代码、数据表或建表脚本；示例需要的表全部由示例自带脚本建立。

#### Scenario: 示例不引用权限模型层的表

- **WHEN** 检查该示例的建表脚本与数据访问代码
- **THEN** 其中不出现权限模型层定义的任何表名
- **AND** 示例启动过程不执行框架级建表脚本

#### Scenario: 权限存储的表名与列名由示例指定

- **WHEN** 示例把权限存储指向一张列名与默认约定完全不同的表
- **THEN** 行级判定、权限读写与数据范围过滤全部按该表正常工作
- **AND** 不需要修改核心层任何代码

#### Scenario: 菜单权限规则由示例自定义

- **WHEN** 示例用自己的规则实现"某个请求路径需要哪种权限"
- **THEN** 核心层的管辖声明与拦截行为按该规则生效
- **AND** 换用另一套规则不影响核心层的判定位置

### Requirement: 每个规格场景都有可指认的验证载体

示例 MUST 为其覆盖的每一项规格场景给出四要素：声明位置、触发方式、观察点、期望结果。凡"方法体是否执行"构成判据的场景，示例 MUST 以可查询的副作用证据判定，而不是以响应内容或响应码代替。

#### Scenario: 拒绝时方法体未执行

- **WHEN** 一次被行级操作权限拒绝的调用发生
- **THEN** 该调用在副作用证据中留下零条记录

#### Scenario: 放行时方法体已执行

- **WHEN** 同一接口在权限补齐后被放行
- **THEN** 副作用证据中出现与本次调用对应的记录

#### Scenario: 语句改写可观测

- **WHEN** 执行一条被声明数据范围的查询
- **THEN** 实际下发的语句可在日志中看到，且其中含有权限过滤条件

#### Scenario: 未被声明的语句不被改写

- **WHEN** 同一次调用中还执行了未被声明的语句
- **THEN** 日志中该语句与业务原文一致，没有附加权限条件

### Requirement: 启动期失败类场景由自动化断言覆盖

对只能在应用启动阶段观察结果的场景，示例 MUST 以自动化测试断言其启动失败及失败原因，MUST NOT 只在文档里描述而不验证。

#### Scenario: 四类声明错误各自断言

- **WHEN** 分别以解析不到语句、语句不是查询、语句启用二级缓存、静态 SQL 中目标表不存在这四种配置启动
- **THEN** 每种配置的启动都失败，且失败信息指到对应的声明位置

#### Scenario: 声明位置错误断言

- **WHEN** 把数据范围声明放在非映射语句的位置上启动
- **THEN** 启动失败并指明该声明不在映射接口上

### Requirement: 验证文档与可执行脚本同源

示例的说明文档 MUST 列出核心能力清单与场景矩阵，并 MUST 说明每项能力"从哪里验证到了哪里"；同时提供一条可执行命令，把矩阵中的用例逐条执行并断言期望，使文档与脚本描述的是同一批用例。

#### Scenario: 脚本可整体复现文档结论

- **WHEN** 按文档说明启动示例后运行该验证命令
- **THEN** 文档中声明已覆盖的用例逐条给出通过或不通过的结论

#### Scenario: 覆盖边界被明确标注

- **WHEN** 阅读说明文档
- **THEN** 文档指出哪些规格场景不在本示例验证范围内，以及由谁验证

### Requirement: 示例的主键形态统一为整型

示例 MUST 只使用整型业务主键，MUST NOT 为演示其他主键形态引入第二套权限存储表或额外的启动配置档。

#### Scenario: 整型主键的不同形态不误判

- **WHEN** 调用方以较短的整型形态提交业务数据ID，而权限表中以较宽的整型形态存储同一主键
- **THEN** 判定放行，不因形态差异误判为未授权

#### Scenario: 其他主键形态不进示例

- **WHEN** 检查示例的建表脚本与配置
- **THEN** 权限存储的数据ID列只有一种整型形态
- **AND** 示例不因主键形态而需要切换配置档
