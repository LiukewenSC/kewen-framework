该目录为 Maven 聚合工程的顶层 POM（artifactId: cu-parent，packaging=pom），通过 `<modules>` 声明 basic、basic-support、boot、sample、other、auth 六个子模块，并在 `<dependencyManagement>` 中以 BOM 方式集中管理 Spring Boot 2.7.18、Spring Cloud 2021.0.9、Spring Cloud Alibaba 2021.0.5.0、MyBatis-Plus 3.5.8、Fastjson/Fastjson2、Hutool、Lombok、P6Spy、Qiniu SDK 等第三方库的版本；同时引入 `spring-boot-autoconfigure-processor` 与 `spring-boot-configuration-processor` 以支持自动装配元数据生成。`.gitignore` 屏蔽 target/.class/IDEA/Eclipse 产物及 *.jks、*.p12、*.keystore、**/logs/** 等敏感文件；`clean-sensitive-files.sh` 使用 `git filter-branch` 批量从 Git 历史中剔除 .jks、logs/、target/ 并提供强制推送指引。
